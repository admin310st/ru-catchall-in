Генератор адресов для catch-all почты

Введите субдомен, который принимает всю почту, выберите вид адресов и получите список уникальных адресов для своего софта. Список собирается в вашем браузере.

Им заканчивается каждый адрес списка. Домен должен принимать почту на любой адрес.

Вид адресов

Spintax: {a|b} выбирает один вариант, %name% берёт переменную из списка ниже. Синтаксис расширенного spintax

Переменные

Переменные подставляются по ссылкам %name% в шаблоне. #set выбирает заново при каждой ссылке, #def выбирает один раз и держит.

Править в Spintax playground

Почему списку нужен catch-all домен

Catch-all домен принимает почту на любой адрес, поэтому придуманный адрес работает с первого письма: заранее ничего создавать не нужно. На домене без catch-all таких адресов нет, и письма на них возвращаются отправителю.

Catch-all домена ещё нет?

Catchall держит catch-all ящик на субдомене вашего домена. В зону добавляются только MX-записи; с токеном Cloudflare или ключом Namecheap это занимает около минуты. Все адреса из списка попадают в один ящик, а софт забирает почту по POP3S или IMAPS. Первый домен стоит $10 за 30 суток, каждый следующий — $3, будь то Standard с одним ящиком или Pro с пятью.

Для чего

Регистрации из своего софта, проверка форм регистрации и приветственных писем, отдельный адрес под каждый сервис, чтобы видеть, кто его слил. Используйте генератор на домене, которым управляете, и соблюдайте правила сайтов, где регистрируетесь.

Вопросы

Уходит ли что-нибудь на сервер?

Нет. Список собирает скрипт в вашем браузере, на наши серверы ничего не отправляется. Только ссылка на playground, если по ней перейти, открывает шаблон, переменные и домен на spintax.net.

Сколько адресов можно сгенерировать?

До 5000 за раз. Если у шаблона меньше сочетаний, генератор остановится и напишет, сколько уникальных адресов нашёл.

Какой синтаксис у шаблона?

Spintax, как на spintax.net: {a|b|c} выбирает один вариант, %name% подставляет переменную, заданную через #set, и при каждом использовании переменная выбирает заново. Ссылка на playground открывает ваш шаблон там для проверки. Полный синтаксис — в справочнике расширенного spintax; длинные шаблоны удобнее писать в Spintax Studio, настольном редакторе для Windows.

Синтаксис расширенного spintax · Spintax Studio: редактор для Windows (на английском)

Можно ли сгенерировать адреса Gmail или Outlook?

Нет. Придуманный адрес на gmail.com либо чей-то, либо не существует. Сгенерированный список принимает почту только на вашем домене с catch-all приёмом.

Как получать почту на эти адреса?

Направьте домен на catch-all ящик. В Catchall ящик живёт на субдомене вашего домена, любой адрес там попадает в него, а читать его можно по POP3S или IMAPS.
